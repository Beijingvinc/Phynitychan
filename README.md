# Phynitychan

<h1>HOW TO SETUP</h1>
<p>To make Phynitychan work, it’s as simple as running python3 Phynitychan.py in your terminal.
But before that, it’s recommended to configure it. If you want to change the password, it’s on line 1005. Once you have everything ready, if you want to access the superadmin panel, you just need to go to /superadmin_gateway.

If you want to change the port, it’s on line 1091.</p>
